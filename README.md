# book-esparcepaz

Libro interactivo **Esparce Paz** en Vite + React (sin Three.js). La interacción de pasar páginas seguirá el patrón de [react-page-flip](https://github.com/ndresx/react-page-flip).

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm run preview` — vista previa del build
